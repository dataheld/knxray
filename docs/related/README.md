- **[AutoBackup](https://it-gmbh.de/en/knx/ets-apps/autobackup/) by IT GmbH**
  (paid, ETS5/6) exports a `.knxproj` file to a configurable folder
  whenever you close a project.
  AutoBackup handles export; knxray handles readable diffs.
  ETS 6.4+ also has a built-in
  [Auto Backup to Archive](https://support.knx.org/hc/en-us/articles/31061986226450-ETS-v6-4-0)
  feature.
  It stores versions inside ETS's archive instead of writing a standalone
  file to a configurable path.
- **[Project Tracing](https://my.knx.org/shop/product?product_type_category=etsapps&product_type=project-tracing)
  by KNX Association** (paid, ETS5/6) logs user actions inside a project,
  including timestamps and user identity.
  It is an audit trail, not a diff view.
- **[Project Comparison](https://it-gmbh.de/en/knx/ets-apps/project-comparison/)
  by IT GmbH** (paid, ETS5 only) compares project snapshots
  and provides navigation to changed elements.
  It is an ETS-native comparison tool, but is not available for ETS6.
